# Vendored ImpulseM protos

Copied unchanged from the ImpulseM repository, `protos/generated/*.proto` and
`protos/generated/v1/types.proto`, at commit `63f0e08`.

Do not edit these files by hand. They are the input of `../gen_tl_proto_map.py`.

`overlays.json` (from `protos/generated/overlays.json`, same commit) is the authoritative list of
ImpulseM extension fields; the generator accepts an extra proto field only if it is listed there.
